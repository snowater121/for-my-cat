GEO ARCADE는 회원가입이 없고, 운영자가 따로 운영하는 서버도 없습니다. 게임 기록은 여러분의 브라우저 안에만 저장됩니다. 다만 사이트를 여는 과정에서 호스팅 업체와 글꼴 제공 업체에 기본적인 접속 정보가 전달되고, 공유 기능을 쓰면 여러분이 고른 정보가 링크에 담깁니다. 아래에 하나씩 적었습니다.

1. 브라우저에 저장되는 정보

게임을 하면 아래 정보가 이 기기의 브라우저 저장소(localStorage, 이름 geoarcade.player.v2)에 저장됩니다. 운영자에게 전송되지 않습니다.

항목내용왜 필요한가
플레이어 이름기록 패널이나 결과 창에 직접 입력한 경우에만기록판·도전장에 표시
게임 기록모드별 최고 기록, 자주 틀린 지역, 플레이 횟수·정답률 등 누적 통계기록판·약점 복습
공부한 날짜라운드를 끝낸 날짜 목록(최대 400일분)연속 공부 표시
업적·오늘의 문제 결과달성한 업적, 날짜별 오늘의 문제 결과(최근 90개)업적 탭, 중복 기록 방지

이 사이트는 쿠키를 만들지 않으며, 광고·방문자 분석 도구를 쓰지 않습니다.

화면을 빨리 열고 오프라인에서도 쓰도록 페이지·아이콘·글꼴의 사본을 브라우저 캐시(서비스워커)에 보관합니다. 개인정보는 들어 있지 않습니다.

2. 여러분이 공유할 때 담기는 정보

결과 창의 결과 공유, 이미지 저장, 도전장 보내기를 누르면 아래 내용이 문구·이미지·링크에 들어갑니다. 직접 누를 때만 만들어지고, 그 뒤에는 여러분이 보낸 상대방이 볼 수 있습니다.

  • 결과 문구·이미지: 지도 종류, 모드, 기록 시간, 정답 수, 연속 공부 일수, 입력한 경우 플레이어 이름
  • 도전장 링크: 위 기록과 이름, 문제 순서를 재현하는 번호. 링크 주소 자체에 들어가므로 링크를 받은 누구나 볼 수 있습니다.

실명 대신 별명을 쓰기를 권합니다.

3. 외부로 전달되는 정보

받는 곳언제전달되는 정보
GitHub (웹 호스팅, GitHub Pages)사이트를 열 때IP 주소, 브라우저 정보 등 일반적인 접속 기록. GitHub 개인정보 보호정책
Google Fonts (글꼴 제공)화면 글꼴을 불러올 때IP 주소, 브라우저 정보. Google 개인정보처리방침

운영자는 위 업체들이 남기는 접속 기록을 받아 보지 않습니다.

4. 공유 랭킹판(Claude 아티팩트 버전)

이 사이트와 별도로, Anthropic의 Claude에서 여는 공유 랭킹판 버전이 있습니다. 그 버전에서 이름을 입력하면 이름과 게임 기록이 Anthropic의 저장소에 올라가 같은 조직(워크스페이스)에서 그 페이지를 볼 수 있는 사람들에게 표시됩니다. 이 GitHub 사이트에서는 해당되지 않습니다.

[입력 필요: 공유 랭킹판 버전을 계속 운영하는지, 누구와 공유하는지 확인 후 이 항목을 유지하거나 삭제]

5. 보관 기간과 삭제

브라우저에 저장된 정보는 여러분이 지울 때까지 남습니다. 운영자는 따로 보관하지 않습니다.

  • 모두 지우기: 브라우저 설정에서 이 사이트(snowater121.github.io)의 사이트 데이터를 삭제하세요.
  • 이름만 지우기: 게임의 🏆 기록 창에서 플레이어 이름 칸을 비우세요.
  • 이미 보낸 공유 문구·도전장 링크는 받은 사람 쪽에 남으므로 운영자가 지울 수 없습니다.
